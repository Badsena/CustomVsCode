Installation & User Manual

Pre-Installation Requirements

  • Ensure that Git is installed on your local computer prior to initiating installation.
  • Git serves as the core engine for automatic background synchronization, version control, and cloud backups of your tests.

Windows Installation

  • Download the Windows executable installer (.exe) from the official secure coordinator link.
  • Right-click the executable and select 'Run as Administrator' (click Yes on the system UAC prompt).
  • Accept the License Agreement and click Next.
  • Retain the default destination path: C:\Program Files\AmypoCoder
  • Keep all additional tasks enabled (Desktop/Start Menu shortcuts, file associations) and click Install.
  • Check the "Launch AmypoCoder" box and click Finish.

macOS Installation

  • Download the certified disk image file (.dmg) from your system coordinator.
  • Double-click the .dmg file to mount it, and drag the AmypoCoder icon into your Applications folder.
  • If blocked or unrecognized (Gatekeeper quarantine):
    • Open Terminal and run:
    • xattr -dr com.apple.quarantine /Applications/AmypoCoder.app
    • open -a "AmypoCoder"
  • Grant permissions for Accessibility, Screen Recording, and Input Monitoring when requested.
  • Restart the application after granting system privileges.

Linux Installation

  • Download the certified disk image file (.deb) from your system coordinator.
  • Open Terminal and redirect to application download folder then run: sudo dpkg -i AmypoEditor.deb to instal application


Common Issues & Troubleshooting

  • Windows SmartScreen Warning: Safe to bypass. Click 'More Info' → 'Run Anyway' to resume setup.
  • "Close Restricted Applications": Ensure software like Skype, Discord, TeamViewer, or VM tools are closed before launching.
  • Internet Connection Error: Verify network status. A stable connection is required to sync test modules.
  • Webcam/Mic Access: Grant camera and microphone permissions when browser/app asks for exam proctoring.

System Requirements

Operating System
  • Windows 10/11 (64-bit)
  • macOS 11.0 (Big Sur) or later
  • Linux (64-bit) — Ubuntu 20.04+
Hardware
  • 2 GHz processor or faster
  • 6 GB RAM (8 GB recommended)
  • 500 MB free disk space
Network
  • Stable internet connection
  • HTTP / HTTPS access to exam portal
  • No VPN restrictions
